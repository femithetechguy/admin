# Technical Skills for 2-5 Years of Experience

The provided image outlines the enhanced skills and technical knowledge required for a BI professional with 2-5 years of experience. The expectations are significantly higher than the entry-level role, focusing on more advanced concepts and hands-on experience.

---

## 1. Expert Level in SQL

A professional at this level is expected to be a master of SQL, moving beyond basic queries to more advanced concepts. This includes:

- **Complex SQL queries:** Proficiency with complex queries, including `CTE` (Common Table Expressions) and `Merge` statements.
- **Stored Procedures:** The ability to write and manage stored procedures for reusable and efficient database operations.
- **Performance Tuning:** Skills in optimizing SQL queries and database performance.

## 2. Basic Knowledge on Data Warehousing Concepts

This role requires a fundamental understanding of how data is structured for analysis. This includes:

- **Dimensional Modeling:** Knowledge of designing data models using a **star** or **snowflake schema**.
- **Fact and Dimension Tables:** A clear understanding of the purpose and design of these table types.
- **Types of Dimension:** Familiarity with different dimension types, including **SCD (Slowly Changing Dimensions)**, which track historical changes in dimension attributes.

## 3. ETL Tool

A BI professional at this stage should have hands-on experience with ETL (Extract, Transform, Load) tools, both on-premises and in the cloud. This includes:

- **SSIS and Azure Data Factory:** Experience in using these tools to build data pipelines.
- **Control Flows and Data Flows:** The ability to design the workflow and data transformation logic within these tools.
- **Scheduling:** Knowledge of how to schedule and automate ETL jobs.

## 4. Business Intelligence

This requires a holistic understanding of the entire BI lifecycle, from start to finish. This includes:

- **Complete BI Module:** The ability to handle a project from the initial requirement gathering phase to final project delivery.

## 5. Power BI Architecture

This goes beyond basic Power BI skills to encompass a deeper understanding of its components and advanced features. This includes:

- **Power Query and Modeling:** Advanced skills in data transformation and data modeling.
- **Relationships:** Expertise in setting up complex relationships and understanding their impact on the model.
- **On-premise Power BI:** Familiarity with on-premises solutions like Power BI Report Server.
- **XVelocity:** Understanding the in-memory, columnar engine (now called **VertiPaq**) that powers Power BI's performance.

## 6. In-depth Understanding of DAX

DAX skills become much more advanced, moving into complex calculations and performance optimization. This includes:

- **Date Calculations:** Proficiency in using time intelligence functions.
- **`CALCULATE` function:** A deep understanding of the most powerful DAX function and how it manipulates filter context.
- **Context Transition:** Knowledge of how row context is converted to filter context.
- **Performance Improvement:** The ability to write efficient DAX code to improve report performance.
- **DirectQuery:** Understanding how to work with DirectQuery models.

## 7. Modeling

Modeling skills at this level focus on best practices for building robust and scalable data models:

- **Avoiding bad relationships:** Knowing when to avoid two-way, many-to-many, or one-to-one relationships, as they can cause performance issues or ambiguity.
- **RLS (Row-Level Security):** The ability to implement dynamic security rules to restrict data access based on the user viewing the report.

## 8. SSAS Knowledge

While not strictly required, knowledge of **SSAS (SQL Server Analysis Services)** is highly recommended. This includes familiarity with building and deploying tabular models, which can be a key part of an enterprise-level BI solution.
