# Technical Skills for 0-2 Years of Experience

The provided image outlines the key skills and technical knowledge required for a Power BI professional with 0-2 years of experience. The requirements are broken down into four main categories.

## 1. Good Knowledge in SQL

A foundational understanding of SQL is essential for a BI professional. This includes:

- **Database concepts:** The ability to understand database structures and how data is organized.
- **DBMS:** Familiarity with Database Management Systems.
- **SQL queries:** Proficiency in writing basic to intermediate queries to retrieve and manipulate data.
- **Joins:** Understanding how to combine data from multiple tables.
- **Views:** Knowledge of creating and using virtual tables.

## 2. Basic Understanding of Power BI Desktop & Services

This category covers the core functionalities of the Power BI platform:

- **Power Query:** The ability to use the Power Query Editor to connect to data sources, clean, and transform data.
- **Modeling:** Skills in building a data model, which includes creating a star schema and setting up relationships between tables.
- **Relationships:** Knowing how to establish and manage relationships between different tables in a data model.
- **Services Deployment:** The ability to publish reports from Power BI Desktop to the Power BI Service and manage them.

## 3. Basic Understanding of DAX

DAX (Data Analysis Expressions) is the formula language used in Power BI for creating calculations. For an entry-level professional, this includes:

- **DAX Understanding:** The fundamental knowledge of what DAX is and how it works.
- **Row Context:** The concept of an expression being evaluated for each row in a table.
- **Filter Context:** The concept of how filters on reports and visuals affect DAX calculations.
- **Measures/Calculated Columns:** The ability to create both measures (dynamic calculations) and calculated columns (static calculations) using DAX.

## 4. Features of Power BI Reporting

This refers to the skills needed to build interactive and user-friendly reports. The key features mentioned are:

- **Drill down:** The ability to navigate from a high-level summary to more detailed data within a visual.
- **Drill through:** The ability to pass a filter context from one report page to another, providing a detailed view of a specific item.
- **Bookmarks:** The ability to capture and save the current state of a report page, including filters and slicers, for later use.
